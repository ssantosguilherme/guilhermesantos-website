📹 Acesso à Webcam

⚠️ Atenção: Para acessar a webcam, seu computador com a câmera deve estar ligado e o VLC rodando.

Clique no botão abaixo para acessar:

Ou copie este link: http://SEU_IP_EXTERNO:8080/

📋 Como configurar:

  1. Verifique seu IP externo (Google "meu ip")
  2. Configure o redirecionamento de porta no roteador (porta 8080)
  3. Substitua "SEU_IP_EXTERNO" acima pelo seu IP real
  4. Mantenha o VLC rodando no computador com a webcam
